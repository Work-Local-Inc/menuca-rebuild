🏗️System Overview

🎯 Core Features

🕷️ Automated Menu Scraping

Universal parser handles 100+ restaurant menu formats using Firecrawl and custom algorithms to extract categories, items, and pricing.

🛒 Intelligent Cart System

Per-restaurant cart persistence using localStorage with cart_{rid} mapping and comprehensive item customization.

💳 Seamless Payments

Stripe integration with order metadata, webhook processing, and automatic tablet forwarding for order fulfillment.

📱 Tablet Integration

Real-time order dispatch to A19 tablet system with v3 schema formatting and multiple endpoint fallbacks.

🔐 Security & Performance

Row Level Security (RLS)

All tables have RLS enabled with tenant-scoped access policies ensuring multi-tenant data isolation.

Performance Indexes

Strategic indexing on foreign keys and tenant_id columns for optimized query performance.

Automatic Timestamps

Trigger-based updated_at maintenance ensures accurate audit trails across all entities.

🔌API Endpoints

🏪 Restaurant Management

POST /api/restaurants/onboard - Create restaurant and trigger menu import
POST /api/agents/create-run - Automated menu scraping with Firecrawl
POST /api/admin/import-legacy-menu - Manual menu import and parsing

💳 Payment Processing

POST /api/stripe/create-checkout-session - Initialize Stripe payment
POST /api/stripe/webhook - Handle payment completion events

📍 Address & Location

POST /api/addresses/validate - Canada Post address validation
GET /api/addresses/details?id={id} - Get address details

📱 Tablet Integration

POST /api/tablet/addOrder - Send order to tablet system
POST /api/test-tablet-integration - Test tablet connectivity

💡Key Technical Insights

🕷️ Universal Menu Parser

Sophisticated parsing system handles 100+ restaurant menu formats using pattern matching, table extraction, and price detection algorithms.

🔄 Hybrid Routing Strategy

Strategic use of Next.js App Router for new features while maintaining Pages Router for complex API integrations.

📊 Multi-Tenant Architecture

tenant_id column throughout schema enables single database to serve hundreds of restaurants with proper data isolation.

⚡ Performance Optimization

Cart persistence via localStorage, intelligent caching, and strategic database indexing for sub-second response times.

⚠️ Critical Production Considerations:
  • Always use production domain for testing: https://menuca-rebuild-pro.vercel.app
  • Supabase MCP for database operations instead of CLI
  • Stripe metadata must include: restaurant_id, items_count, delivery_*
  • Never bypass delivery capture step in checkout flow
  • Tablet integration requires multiple endpoint fallbacks
